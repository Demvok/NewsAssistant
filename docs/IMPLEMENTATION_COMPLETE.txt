✅ AGENT ROLES & RESPONSIBILITIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JOURNALIST (News Analyst)
├─ Input: Query + Retrieved context
├─ Process: Analyzes with corpus evidence
├─ Output: Comprehensive analysis
└─ Creates: AgentTrace with initial analysis reasoning

FACT CHECKER (Verification Specialist)
├─ Input: Query + Analysis + Original context
├─ Process: Verifies claims against corpus
├─ Output: Critical evaluation & critique
└─ Creates: AgentTrace with verification reasoning

EDITOR (Synthesis & Refinement)
├─ Input: All previous outputs
├─ Process: Balances analysis & critique
├─ Output: Final polished answer
└─ Creates: AgentTrace with synthesis reasoning


✅ TRACE INFORMATION SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Each agent creates an AgentTrace containing:

  agent_name     - "Journalist", "Fact Checker", "Editor"
  role           - Full role description for UI
  input_text     - Summarized input to agent
  output_text    - Complete agent response
  reasoning      - Why agent produced this output
  timestamp      - ISO 8601 format for performance tracking

All traces collected in result['traces'] for complete audit trail.

  from core.rag import retrieve_context

  # Get user query
  query = "What are the main topics in the news corpus?"

  # Retrieve context (optional)
  context = retrieve_context(query, top_k=5)

  # Run multi-agent pipeline
  result = run_multi_agent_pipeline(query, context)

  # Display results
  print("Final Answer:", result['final_answer'])

  # Inspect agent traces
  for trace in result['traces']:
      print(f"{trace['agent_name']} ({trace['role']})")
      print(f"  Reasoning: {trace['reasoning']}")
